# SNSコンテンツ管理システム

## 概要
地方フルリモートエンジニアとしての日常・リアルを、X / Threads / Instagram / TikTok / note の5媒体で発信するためのコンテンツ管理システムです。

発信コンセプトは「地方フルリモートエンジニアの日常・リアルを発信し、その生活に憧れを感じてもらうこと」。最終的にはnoteや直接問い合わせへ、営業感なく自然に読者を導くことを目指します。

## ディレクトリ構成

```
sns-manager/
├── skills/            # 各媒体ごとの投稿ルール・型・トーンを定義
│   ├── x.md
│   ├── threads.md
│   ├── instagram.md
│   ├── tiktok.md
│   └── note.md
├── data/
│   ├── posts/          # 媒体ごとの投稿記録（実績データ）
│   │   ├── x.json
│   │   ├── threads.json
│   │   ├── instagram.json
│   │   └── tiktok.json
│   └── profile.json    # 発信者プロフィール・コンセプト定義
├── drafts/              # 投稿前の下書きを一時保存する場所
│   └── .gitkeep
└── README.md
```

### `skills/`
各SNS媒体の特性（文字数、トーン、投稿の型、アルゴリズム特性、NGパターンなど）をまとめたガイドラインです。投稿文を作成する際は、対象媒体の該当ファイルを参照してルールに沿った内容を作成してください。

### `data/profile.json`
発信者のプロフィールと発信コンセプトを保持する設定ファイルです。投稿内容がコンセプトからブレていないかを確認する際の基準になります。

### `data/posts/*.json`
媒体ごとに投稿を記録するデータファイルです。各投稿は以下のスキーマで記録します。

```json
{
  "id": "YYYYMMDD-001",
  "date": "YYYY-MM-DD",
  "platform": "X",
  "theme": "投稿のテーマ",
  "text": "投稿本文",
  "status": "投稿済み | 未投稿 | 見送り",
  "reaction": {
    "likes": 0,
    "reposts": 0,
    "replies": 0,
    "bookmarks": 0
  },
  "memo": "振り返りメモ",
  "rating": "良かった | 普通 | 微妙"
}
```

### `drafts/`
投稿前のアイデアや下書きを一時的に置いておく場所です。清書・投稿後は `data/posts/` へ記録として移管してください。

## 投稿生成の使い方
1. 投稿したい媒体を決め、`skills/` 配下の該当ファイル（例：Xなら `skills/x.md`）を読み、文字数・トーン・投稿の型・NGパターンを確認する。
2. `data/profile.json` のコンセプト・NG項目と照らし合わせ、発信テーマを決める。
3. スキルファイルのルールに沿って本文を作成し、必要であれば `drafts/` に下書きとして保存する。
4. 内容を確定させたら投稿し、`data/posts/<媒体>.json` の `posts` 配列に、上記スキーマに沿ったオブジェクトを追記する。

## データ記録の方法
- 投稿した（または見送った）都度、該当媒体の `data/posts/*.json` にレコードを追加します。
- `status` は `投稿済み | 未投稿 | 見送り` のいずれかを設定します。
- 投稿後、一定期間が経過したら `reaction`（いいね・リポスト・返信・保存数など）を実績値で更新します。
- `memo` と `rating` に振り返りを記録し、次回以降のテーマ選定・改善に活用します。
