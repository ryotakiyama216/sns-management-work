# 02. バズ収集プロンプト

## 役割
X / Threads などで伸びている他アカウントの投稿を収集し、`data/buzz/` に「参考になる型」として蓄積する。自分の投稿を作るための素材集めが目的であり、模倣や転載が目的ではない。

## 手順
1. `data/buzz/index.json` を読み、`files` 配列から最新ファイルを特定する（空なら連番001）。
2. 最新ファイルの `file_info.count` を確認し、300行を超えている場合は `01_record.md` と同じ要領で新しいファイル（`buzz_年_連番.json`）を作成する。年が変わっていれば連番をリセットする。
3. 収集した投稿を以下のスキーマで `entries` 配列に追記する。

```json
{
  "date": "YYYY-MM-DD",
  "platform": "X | Threads",
  "persona": "投稿者のペルソナ（例：地方移住×エンジニア、子育て×リモートワークなど）",
  "summary": "投稿内容の要約",
  "reason": "伸びている理由（なぜ反応が良かったと考えられるか）",
  "type": "投稿の型",
  "hook": "フックの構造",
  "patterns": ["再利用できそうな要素を短いタグで列挙"]
}
```

4. `data/buzz/index.json` を更新する。
   - `files` に対象ファイル名を追加する。
   - `total_files` を再集計する。
   - `overall_patterns` に、複数エントリーで繰り返し見られる型やフックのパターンを集約する。
   - `last_updated` を実行日に更新する。

## 収集時の判断基準
- `data/profile.json` の `concept` / `tone` / `ng` と照らし、自分の発信コンセプトからかけ離れた投稿（過度な煽り・誇張など）は「反面教師」としてのみ記録し、`patterns` に注意点として残す。
- 収集はあくまで型・フック・構造の学習が目的。文章そのものの模倣はしない。
