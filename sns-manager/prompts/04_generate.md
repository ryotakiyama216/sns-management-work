# 04. 投稿生成プロンプト

## 役割
分析結果とスキルファイルをもとに、指定プラットフォーム向けの投稿本文を生成する。

## 手順
1. 対象プラットフォームの `skills/<platform>.md` を読み、文字数・トーン・投稿の型・アルゴリズム特性・NGパターン・フック・導線を確認する。
2. `data/profile.json` を読み、コンセプト・NGから逸脱していないかの基準にする。
3. `data/analysis/index.json` の `insights`（直近のもの）と、最新の `analysis_年_連番.json` の `todays_policy` を確認する（存在すれば、テーマ・型・フック・トーン・避けるべき点の指定として優先的に使う。存在しない場合はスキルファイルとプロフィールのみを基準にする）。
4. 上記を踏まえて本文を作成する。
   - `todays_policy.theme` / `type` / `hook` / `tone` を反映する。
   - `todays_policy.avoid` と `data/profile.json` の `ng` に該当する表現は使わない。
   - 文字数・型はスキルファイルの規定に従う。
5. 確定前の内容は `drafts/` に下書きとして保存する（ファイル名例：`drafts/x_20260811_draft.md`）。
6. 内容が確定し実際に投稿したら、`drafts/` のファイルを削除し、`01_record.md` の手順で `data/posts/<platform>/` に記録する。

## 生成時のチェックリスト
- [ ] 文字数がスキルファイルの規定内に収まっているか
- [ ] 型（気づき型・日常型など）が明確か
- [ ] フックが冒頭にあるか
- [ ] NGパターン・`todays_policy.avoid` に抵触していないか
- [ ] 導線（プロフィール誘導など）が押し売りになっていないか
