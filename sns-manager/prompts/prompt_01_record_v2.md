# ① 記録プロンプト v2（毎晩実行）

## 役割
当日の投稿データをJSONファイルに記録し、index.jsonを更新してください。
300行ルールを自動でチェックして、必要であれば新しいファイルを作成してください。

---

## 手順

### STEP1｜記録するデータを入力する

```
【記録する投稿情報】
- 投稿日：
- プラットフォーム（X / Threads / Instagram / TikTok）：
- 投稿テーマ：
- 投稿本文：
- 投稿の型（気づき型 / リアル日常型 / 問いかけ型）：
- フックの構造（最初の1行がどう作られているか）：
- いいね数：
- リポスト・シェア数：
- リプライ・コメント数：
- 保存・ブックマーク数：
- 自己評価（良かった / 普通 / 微妙）：
- 振り返りメモ：
```

### STEP2｜ファイルを確認する
該当プラットフォームのフォルダを確認してください。

```
sns-manager/data/posts/[プラットフォーム]/index.json
```

index.jsonを読み込み、最新のデータファイル名を確認する。

### STEP3｜300行ルールをチェックする
最新のデータファイルの行数を確認する。

- **300行未満** → そのファイルに追記する
- **300行以上** → 新しいファイルを作成する

新しいファイルを作成する場合のファイル名：
```
[platform]_[year]_[連番3桁].json
例：x_2025_002.json
```

新しいファイルの冒頭に `file_info` を設定する：
```json
{
  "file_info": {
    "platform": "X",
    "file_number": 2,
    "year": 2025,
    "from": "YYYY-MM-DD",
    "to": "YYYY-MM-DD",
    "count": 0,
    "max_rows": 300
  },
  "posts": []
}
```

### STEP4｜投稿データを追記する
以下のスキーマで追記する。

```json
{
  "id": "20251001-001",
  "date": "YYYY-MM-DD",
  "theme": "投稿のテーマ",
  "text": "投稿本文",
  "type": "気づき型 | リアル日常型 | 問いかけ型",
  "hook": "フックの構造メモ",
  "status": "投稿済み",
  "reaction": {
    "likes": 0,
    "reposts": 0,
    "replies": 0,
    "bookmarks": 0
  },
  "rating": "良かった | 普通 | 微妙",
  "memo": "振り返りメモ"
}
```

### STEP5｜index.jsonを更新する
```json
{
  "platform": "X",
  "last_updated": "YYYY-MM-DD",
  "total_posts": 累計投稿数,
  "files": [
    {
      "file": "x_2025_001.json",
      "from": "最初の投稿日",
      "to": "最新の投稿日",
      "count": このファイルの投稿数
    }
  ],
  "overall_summary": {
    "best_theme": "最も評価が高いテーマ",
    "best_type": "最も評価が高い型",
    "avg_likes": 平均いいね数,
    "avg_replies": 平均リプライ数,
    "avg_bookmarks": 平均保存数,
    "top_patterns": ["上位パターン1", "上位パターン2"]
  }
}
```

### STEP6｜完了を報告する
```
✅ 記録完了
- プラットフォーム：
- 投稿日：
- テーマ：
- 自己評価：
- 保存先ファイル：
- このファイルの件数：○件 / 300行
- 累計記録数：○件
- 次のファイル作成まで：あと○行
```

---

## 注意事項
- 既存データは絶対に上書き・削除しない
- 複数プラットフォームを同時に記録する場合はそれぞれのフォルダに追記する
- idは「日付-連番」形式（同日複数投稿の場合は -002, -003 と増やす）
- overall_summaryは蓄積データ全体を見て更新する
