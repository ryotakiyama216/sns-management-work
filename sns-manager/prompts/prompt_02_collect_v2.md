# ② 収集プロンプト v2（毎朝実行）

## 役割
Web検索でX・Threadsのバズ投稿を収集し、buzz/フォルダに保存・index.jsonを更新してください。

---

## 手順

### STEP1｜index.jsonを読み込む
```
sns-manager/data/buzz/index.json
```
最新のbuzzファイルを確認し、300行ルールをチェックする。

- **300行未満** → 最新ファイルに追記する
- **300行以上** → 新しいファイルを作成する（例：buzz_2025_002.json）

### STEP2｜検索キーワードで調査する

**メインキーワード**
- 地方エンジニア
- フルリモートエンジニア
- リモートワーク エンジニア
- 地方移住 エンジニア
- フリーランスエンジニア 日常

**サブキーワード（ローテーションで使う）**
- 地方移住 リアル
- フルリモート 働き方
- エンジニア 子育て
- フリーランス 案件
- 在宅ワーク 日常

### STEP3｜バズ投稿を5〜10件収集する

選定条件：
- いいね・リポスト・コメントが多いもの
- 投稿者のペルソナが発信者と近いもの
- 直近1〜2週間以内の投稿を優先
- 同じアカウントから複数収集しない

各投稿について記録：
```
- プラットフォーム：X / Threads
- 投稿者ペルソナ：
- 投稿内容（要約）：
- 伸びている理由（推測）：
- 使われている型：
- フックの構造：
```

### STEP4｜パターンサマリーをまとめる
```
【今日のバズパターン】
1. パターン名：
   特徴：
2. パターン名：
   特徴：
3. パターン名：
   特徴：
```

### STEP5｜buzzファイルに追記する
```json
{
  "date": "YYYY-MM-DD",
  "platform": "X",
  "persona": "投稿者のペルソナ",
  "summary": "投稿内容の要約",
  "reason": "伸びている理由",
  "type": "投稿の型",
  "hook": "フックの構造",
  "patterns": ["パターン1", "パターン2"]
}
```

### STEP6｜buzz/index.jsonを更新する
```json
{
  "last_updated": "YYYY-MM-DD",
  "total_files": ファイル数,
  "files": [
    {
      "file": "buzz_2025_001.json",
      "from": "開始日",
      "to": "最終更新日",
      "count": 件数
    }
  ],
  "overall_patterns": ["全期間を通じて多いパターン1", "パターン2"]
}
```

### STEP7｜完了を報告する
```
✅ 収集完了
- 収集件数：○件
- 保存先：buzz_2025_00○.json
- 今日のバズパターントップ3：
  1.
  2.
  3.
- 次のステップ：③ 分析プロンプトを実行してください
```

---

## 注意事項
- 投稿内容は要約して記録する（著作権への配慮）
- 「なぜ伸びているか」の推測を必ず入れること
- 過去のbuzzファイルのoverall_patternsも参照してトレンドの変化を観察する
