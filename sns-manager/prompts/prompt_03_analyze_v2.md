# ③ 分析プロンプト v2（毎朝・②収集の直後に実行）

## 役割
index.jsonを入口に必要なデータだけを読み込み、自分の投稿データとバズデータを照合して
今日の投稿方針をまとめ、analysis/フォルダに保存してください。

---

## 手順

### STEP1｜index.jsonだけを先に読む（軽量参照）
以下の4つのindex.jsonを読み込む。生データファイルはまだ読まない。

```
sns-manager/data/posts/x/index.json
sns-manager/data/posts/threads/index.json
sns-manager/data/buzz/index.json
sns-manager/data/analysis/index.json
```

index.jsonのoverall_summaryとoverall_patternsを確認して、全体傾向を把握する。

### STEP2｜必要なファイルだけを追加で読む
以下の優先順位で、必要最小限のファイルだけを読む。

```
① 各プラットフォームの最新データファイル（直近の投稿を確認するため）
② 今日のbuzzファイル（②収集で作成されたもの）
```

過去の古いデータファイルは読まない。index.jsonのsummaryで代替する。

### STEP3｜自分の投稿を分析する

**① 評価別の傾向**
```
【良かった投稿の共通点】
- テーマ：
- 型：
- フックの特徴：
- トーンの特徴：

【微妙だった投稿の共通点】
- テーマ：
- 改善ポイント：
```

**② 反応数の傾向**
```
【反応が高かった投稿の特徴】
- 共通するテーマ：
- 共通する型：
- フックの特徴：
```

**③ 直近5件のテーマ確認（重複回避）**
```
【直近5件のテーマ】
1.
2.
3.
4.
5.
→ 今日避けるべきテーマ：
```

### STEP4｜バズデータと照合する
```
【自分がまだ試せていないバズパターン】
1.
2.

【自分の強みと掛け合わせやすいバズパターン】
1.
2.

【今日最も有効そうな切り口】
→
```

### STEP5｜今日の投稿方針をまとめる
```
═══════════════════════════════
📊 今日の投稿方針サマリー
───────────────────────────────
【推奨テーマ】
→

【推奨する型】
→

【フックの方向性】
→

【トーン】
→

【避けること】
→

【一言コメント】
→
═══════════════════════════════
```

### STEP6｜analysis/フォルダに保存する

analysis/index.jsonを確認して300行ルールをチェック。

保存するエントリー：
```json
{
  "date": "YYYY-MM-DD",
  "good_patterns": [],
  "bad_patterns": [],
  "buzz_patterns": [],
  "todays_policy": {
    "theme": "",
    "type": "",
    "hook": "",
    "tone": "",
    "avoid": []
  },
  "insight": "今日気づいた重要なポイント"
}
```

analysis/index.jsonを更新：
```json
{
  "last_updated": "YYYY-MM-DD",
  "total_files": ファイル数,
  "files": [
    {
      "file": "analysis_2025_001.json",
      "from": "開始日",
      "to": "最終更新日",
      "count": 件数
    }
  ],
  "insights": ["全期間を通じて重要なインサイト1", "インサイト2"]
}
```

### STEP7｜完了を報告する
```
✅ 分析完了
- 参照したファイル：（読み込んだファイル名のみ）
- 分析した投稿数：○件
- 参照したバズ投稿数：○件
- 今日の推奨テーマ：
- 保存先：analysis_2025_00○.json
- 次のステップ：④ 生成プロンプトを実行してください
```

---

## 注意事項
- index.jsonのsummaryで足りる場合は生データを読まない（コンテキスト節約）
- データが少ない初期は感覚ベースの分析でOK。続けるほど精度が上がる
- 分析結果の「今日の投稿方針サマリー」をそのまま④生成プロンプトに渡す
