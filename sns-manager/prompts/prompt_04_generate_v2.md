# ④ 生成プロンプト v2（毎朝・③分析の直後に実行）

## 役割
分析結果・スキルファイル・今日のエピソードをもとに、X・Threadsの投稿を生成してください。

---

## 手順

### STEP1｜スキルファイルとプロフィールを読み込む
```
sns-manager/skills/x.md
sns-manager/skills/threads.md
sns-manager/data/profile.json
```

生データファイルは読まない。③の分析結果を使う。

### STEP2｜③の分析結果を受け取る
③分析プロンプトで出力された「今日の投稿方針サマリー」を貼り付けてください。

```
【今日の投稿方針サマリーをここに貼る】


```

### STEP3｜今日のエピソードを入力する
実際にあったこと・感じたことを一言でOKです。

```
【今日のエピソード】


```

※ エピソードがない場合は「なし」と入力してください。
　 その場合は方針サマリーから最適なテーマを提案します。

### STEP4｜投稿を生成する

**共通ルール**
- プロフィールのトーン（等身大・共感重視・営業感なし）を守る
- 方針サマリーの「避けること」を必ず守る
- 今日のエピソードを実体験として盛り込む
- 押し売りなし。プロフィールへの自然な誘導のみ
- 誇張・煽り・直接的な宣伝は使わない

**X用ルール**
- 140字以内（必ず守る）
- 最初の1行でフックを作る
- 改行を効果的に使う

**Threads用ルール**
- 150〜250字
- 会話的なトーン
- 最後に問いかけを入れてコメントを促す

### STEP5｜生成結果を出力する

```
═══════════════════════════════
📝 本日の投稿ドラフト
───────────────────────────────

【X】


文字数：○字
使った型：
フックの構造：

───────────────────────────────

【Threads】


文字数：○字
使った型：
問いかけの意図：

───────────────────────────────

【生成の根拠】
- 参考にしたバズパターン：
- 避けた直近のテーマ：
- 今日の方針との合致点：
═══════════════════════════════
```

### STEP6｜投稿後の記録を促す
```
✅ 生成完了

投稿したら ① 記録プロンプト で反応を記録してください。
蓄積されるほど、明日の生成精度が上がります。
```

---

## 注意事項
- 気に入らない場合は「もっと〇〇な感じで」と伝えれば再生成する
- エピソードがない場合、方針サマリーのテーマから生成する
- 投稿後は必ず①記録プロンプトで反応を記録すること
