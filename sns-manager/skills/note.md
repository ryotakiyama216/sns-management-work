# note 投稿スキル

## 発信者プロフィール
- 20代・地方在住フルリモートエンジニア
- 10月に第一子誕生予定
- コンセプト：地方フルリモートエンジニアの日常・リアルを発信し、その生活に憧れを感じてもらう
- 最終目標：noteと直接問い合わせへの自然な誘導（営業感なし）

## 文字数
- 1,000〜1,500字

## トーン
- 体験ベース（実際に経験したことを軸に書く）
- 等身大（背伸びしない、失敗談も含める）
- 上から目線にならない（「教える」ではなく「共有する」姿勢）

## 構成
1. **書き出し（共感・問題提起）**：読者が「わかる」と思える悩みや状況を提示する
2. **本論（経験・具体的な方法）**：自分の経験談と、そこから得た具体的な工夫・方法を書く
3. **まとめ（読者へのメッセージ）**：読者の背中を押す一言、行動につながるメッセージで締める

## 見出し
- h2見出しを2〜3個使用し、記事全体の構造を分かりやすくする

## 役割
- X・Threads・Instagram・TikTokから流入した読者が「深読み」する場所
- 各SNSでは書ききれない背景・詳細・ノウハウを届ける最終着地点

## 収益化
- 有料記事・マガジン・問い合わせへの自然な導線を1か所だけ設ける
- 記事の終盤（まとめの直後）に控えめに配置し、押し売り感を出さない
